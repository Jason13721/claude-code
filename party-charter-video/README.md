# 党章智能体 —— 一部根据可行性研究报告制作的科普视频

把《中共二大与党章研究 AI 智能体项目可行性研究报告》（2026 年 10 月）改编成约 11 分 20 秒、1080p/30fps 的中文科普视频，面向高中生。

画面由 JavaScript + Canvas 2D 逐帧绘制，配音由本地神经网络 TTS 生成，背景音乐和音效由程序合成。渲染流程和 `../transformer-video` 相同，引擎改成了红金配色，并新增了石库门、关卡拱门、印章、服务器等图标（`src/common.js`）。

## 生成

```bash
npm install
# models/ 指向 ../transformer-video/models（MeloTTS + Paraformer），下载方法见那边的 README
npm run lines && npm run tts && npm run cues && npm run audio
npm run render        # → out/party-charter.mp4
```

`release/party-charter-720p.mp4` 是提交进仓库的 720p 成片。
